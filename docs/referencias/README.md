# Referencias visuales (bocetos)

Bocetos generados con **Google Stitch** para el login, Resumen, Niveles, Muertes y Logros y
exploración. Se usaron solo como **inspiración de composición** (jerarquía, orden de las
tarjetas, cabeceras, tablas), no como diseño a copiar.

- **Los datos son inventados y no representan al sistema real**: niveles, logros, rarezas,
  zonas, tendencias, plataformas, textos de diagnóstico y cifras no salen de la API ni de los
  catálogos de los juegos.
- No se copió código ni estilos generados por Stitch.
- La fuente de verdad visual es [`docs/DISENO_DASHBOARD.md`](../DISENO_DASHBOARD.md) y los
  tokens de `dashboard/src/styles/tokens.css`. Si un boceto contradice ese documento, gana el
  documento.
